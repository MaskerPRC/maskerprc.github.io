前向模式 AD

前向模式 AD 的核心逻辑（基于“双张量”）现在已集成到 PyTorch 中。所有用于操作此类张量、代码生成和视图处理的 API 已在 master (1.9.0a0) 中。下个月将添加 Gradcheck 和一组公式；今年晚些时候将实现所有 PyTorch 函数、自定义 Autograd 函数和更高阶梯度的全面支持。了解更多信息或与 @albanD 在相应的 RFC 上分享您的反馈。

使复共轭运算变得懒加载

PR #54987 对复数张量的共轭操作返回一个具有特殊 is_conj() 位翻转的视图。除了通过不创建完整张量来节省内存外，如果后续操作可以直接处理共轭输入，这还可能带来速度提升。对于此类操作（如 gemm ），会向底层 API 传递一个标志；对于其他操作，则在传递给操作之前将共轭操作化为具体形式。

torch.use_deterministic_algorithms 已稳定

torch.use_deterministic_algorithms() （文档）在 master (1.9.0a0) 中已稳定。如果为 True，则标志将非确定性操作切换到可用的确定性实现，如果不可用，则抛出 RuntimeError 。

torch.linalg 和 torch.special

torch.linalg 现已稳定；该模块与 NumPy 的 np.linalg 线性代数函数保持一致。 torch.special （beta）包含 scipy.special 中的函数。如果您想为 torch.special 贡献函数，请查看此跟踪问题。如果您想添加列表中尚未出现的函数，请在跟踪问题中说明您的用例以及为什么应该添加该函数。

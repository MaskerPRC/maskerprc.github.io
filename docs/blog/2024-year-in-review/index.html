2024年12月23日

PyTorch 成为 AI 和 ML 领域主导的开源框架：2024 年回顾

作者：Eli Uriegas，Meta 和 Jennifer Bly，PyTorch 基金会

过去一年对 PyTorch 来说是里程碑式的一年，从重大发布到旗舰 PyTorch 大会，我们都见证了来自 3500 多名个人和 3000 多家组织的令人难以置信的增长。可以说，PyTorch 现在已经成为 AI/ML 领域的深度学习主导框架。根据 Linux 基金会最近发布的《塑造生成式 AI 未来报告》，PyTorch 在模型训练领域以 63%的采用率领先。

PyTorch 基金会于 2022 年成立，旨在通过培养和维持一个以 PyTorch 为中心的开源、供应商中立项目生态系统来推动 AI 工具的采用。今天，它仍然是一个充满活力、协作的枢纽，由深度学习社区创建和运营。随着我们结束这一年，让我们回顾一下一些亮点以及这一年是如何在增长、合作、创新和社区中度过的一年。

2024年亮点：增长与影响的一年

本年 PyTorch 加速了其增长。贡献增长了 133%，比去年全球组织数量翻了一番。

该项目在 PyTorch 新仓库的使用上实现了 20%的同比增长，去年一年中，分支和用户数量增长了 30%。

现在超过 70%的 AI 研究实现正在使用 PyTorch。

数据基于《2024 年 Linux 基金会年度报告 》。

PyTorch 工具生态系统增长了超过 25%，增强了软件和硬件能力。与所有主要云服务提供商、数十家主要软件供应商和行业合作伙伴合作，PyTorch 正在为 AI 创新的步伐和广度设定新的标杆。

今年，PyTorch 在 2.2、2.3、2.4 和 2.5 版本中推出了 4 个里程碑式的发布。我们观察到了各种标志性功能的发布，如 AOTInductor、FlashAttention-2 支持 、Tensor 并行性 、新的 Python 自定义操作 API 以及 FlexAttention 的引入。来自 PyTorch 基金会成员公司的工程师们也聚集在一起，为 Intel GPU（XPU）、AWS Graviton 处理器、Inductor 性能等平台提供支持和优化。

全年，PyTorch 团队一直在努力引入一系列新的 PyTorch 原生库！ExecuTorch 团队与 Arm、Apple 和高通技术公司合作发布了他们的 alpha 版本，随后迅速发布了专注于稳定性和添加联发科的 beta 版本。TorchTune 建立了一个 PyTorch 原生库，可以轻松微调大型语言模型。TorchAO 引入了一个 PyTorch 原生库，通过利用低比特数据类型、量化和稀疏性，使模型更快更小。TorchCodec 的推出为开发者提供了一个简单、高效且 PyTorch 原生的方法来将视频解码为张量。TorchRec 1.0 版本发布，这是 PyTorch 原生推荐系统库的第一个稳定版本。

我们在今年还举办了许多技术展示，以展示 PyTorch 的强大功能！ 火盾 Titan 展示了一个开源的、PyTorch 原生分布式训练系统，该系统可以用于训练大型语言模型（LLMs）。 火聊 Chat 展示了如何在笔记本电脑、台式机和移动设备上无缝且高效地运行 LLMs。

此外，我们非常高兴在 2024 年将多个新项目纳入 PyTorch 生态系统，包括将大语言模型（vLLM） 引入 PyTorch 生态系统，这是一个最先进的推理引擎，为机器学习工程师提供了一种简单、快速且经济的部署 LLMs 的方法。如果您有兴趣加入 PyTorch 生态系统，请加入 ！

6 月在法国巴黎，我们首映了官方 PyTorch 纪录片 ，该纪录片聚焦于 PyTorch 充满活力的生态系统及其在推动 AI 创新中的作用。影片揭示了 PyTorch 诞生的真实故事，将其归功于一群默默无闻的英雄，他们推动着技术创新。

2024 年 PyTorch 大会吸引了是 2023 年的三倍注册人数，反映了围绕开源技术的 AI 和机器学习社区的快速增长。为期两天的活动包括关于 AI 未来的深入讨论、动手实践环节和热烈的讨论，涵盖了从生成式 AI 到大型语言模型的所有内容。

新的初创企业展示环节让早期创始人向顶级风险投资家展示他们的 AI 初创企业，深度学习编译器迷你峰会深入探讨了正在改变 AI 工作负载的深度学习编译器的进展，而微调迷你峰会汇集了一个充满活力的研究人员、开发者、实践者和爱好者的社区，讨论了内存效率、参数高效微调和大规模性能等主题。

优秀贡献者获得了 PyTorch 贡献者奖 。祝贺今年获得提名的获奖者，他们是一群在 PyTorch 今年旅程中发挥关键作用的杰出个人和团队。

PyTorch 基金会成员数量今年随着 Arm 和 Rebellions 的加入而增长。截至年底，首任成员包括：AMD、Arm、AWS、Google Cloud、华为、Hugging Face、IBM、Intel、Lightning AI、Meta、Microsoft Azure 和 NVIDIA。普通成员包括：Graphcore、Rebellions 和 Snowflake。如果您所在的组织有兴趣加入，请了解如何成为 PyTorch 基金会的成员 。

PyTorch 举办了众多线上线下活动，包括 PyTorch 文档马拉松 ，贡献者在此活动中努力改进 PyTorch 文档并促进协作，全球各地的本地聚会将来自上海到首尔等地的感兴趣人士聚集在一起，以及在我们的夏季网络研讨会系列、现场问答和专家交流中，超过十场网络研讨会吸引了来自世界各地的参与者。

PyTorch 基金会今年迎来了新的领导层。 执行董事马特·怀特于 4 月接任，并立即开始提升 PyTorch 在人工智能领域的知名度。技术顾问委员会（TAC）也选举了新的领导层 ，由 Luca Antiga（Lightning AI）担任主席，Jiong Gong（英特尔）担任副主席。

PyTorch 管理委员会继续制定方向，并领导基金会完成其使命。PyTorch 市场营销和推广委员会开发了计划，以最大化 PyTorch 的可见性并推进社区的利益。PyTorch CI 工作组聚集在一起，成功地将 PyTorch CI 管道迁移到 Linux 基金会。

我们的社会媒体社区与我们一起，在 X、LinkedIn、Facebook 和 YouTube 上拥有 77.5 万名粉丝，全年 PyTorch 内容的曝光量超过 1200 万次。PyTorch 生态系统也不断发展壮大，添加了许多新项目，以利用 PyTorch 深度学习在许多垂直领域的应用。

PyTorch 在媒体中被提及，在顶级科技出版物如《The New Stack》的 《为什么 PyTorch 备受宠爱》 文章和《InfoWorld》的 《TorchAO PyTorch 库如何使模型更快更小》 文章中。

我们今年发布了 74 篇技术和社区博客，近千万人访问了 PyTorch 网站。

感谢每一位帮助今年取得卓越成就的你们！过去一年 PyTorch 所经历的演变和增长，得益于这个令人惊叹的社区的激情、奉献和独创性。展望明年，我们期待着在这个势头的基础上继续前进，继续推动人工智能的边界。

请记住，PyTorch 大会将于 2025 年 10 月 22 日至 23 日在旧金山举行。2025 年将带来更大的创新和更紧密的社区合作。

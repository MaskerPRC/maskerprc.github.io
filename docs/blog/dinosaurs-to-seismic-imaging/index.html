2023年12月12日

来自 PyTorch Conference 2023：从恐龙到地震成像，用 Intel

由拉玛亚·拉维、苏珊·卡勒尔在英特尔撰写

短讲 1：使用 OpenFWI 将地震数据转换为地下模型

演讲者：本杰明·康索尔沃，英特尔 AI 软件工程经理， 领英

会议概览

在本节中，本（Ben）首先概述了地震成像和全波形反演（FWI）。地震成像和 FWI 帮助我们探索陆地上的重要地下矿产资源，这些资源对于人类的繁荣至关重要。为了找到这些关键的地下矿产资源，我们需要以高精度、低成本的方式对地下进行成像，这涉及到两个主要挑战。他解释了利用 AI 解决这些挑战的方案，具体如下。

挑战 利用 AI 的解决方案
传统基于物理的 FWI 需要准确的起始模型。 数据驱动的深度学习解决方案不需要一个精确的起始模型。
GPU 通常用于微调神经网络，但往往不可用且昂贵。 CPU 高度可用、价格低廉，适用于人工智能微调。新一代英特尔® 至强® 可扩展处理器内置人工智能加速引擎，称为英特尔® AMX（英特尔® 高级矩阵扩展），有助于加速人工智能训练和推理性能。

接下来，他展示了地下模型和相应的地震测线数据的波传播。在他的例子中，测线数据是由地雷爆炸或振动地震车等爆炸声记录的合成时间采样记录，这些记录由遍布广大地区的地震仪记录。对于这个应用，训练数据包括地下模型图像和地震测线图像一对，其中从测线数据预测模型。

地震炮图像数量 地下模型图像数量
训练 120,000 24,000
测试 25,000 5,000
验证 5,000 1,000

在本应用中，训练过程中使用的算法是 InversionNET（编码器-解码器卷积神经网络）。请查看 Deng 等人（2021 年）中关于 InversionNET 架构实现的详细信息。 邓等（2021 年）

然后他展示了结果：

  1. 预测模型与真实模型在一轮和 50 轮训练后的对比。在训练 InversionNET 后，预测模型与真实图像更加接近。
  2. 随着时间推移，训练损失和验证损失曲线在 50 个 epoch 中逐渐下降。

最后，本总结了他的演讲，强调他能够在没有准确起始模型的情况下，在第四代 Intel® Xeon® Scalable 处理器上成功微调深度神经网络，以获得地下模型。

在这里观看完整视频录像 ，下载演示文稿 。更多详情请参阅此博客 。

关于演讲者

本·康索沃是英特尔的人工智能解决方案工程经理。他一直在构建一个围绕英特尔人工智能技术和英特尔硬件产品提供的团队和项目。他拥有数据科学背景和热情，特别是在深度学习（DL）和计算机视觉方面。他将深度学习技能应用于网络安全行业，以自动识别钓鱼网站，以及应用于石油和天然气行业，以识别地球物理成像的地下特征。

闪电演讲2：恐龙化石寻踪

演讲者：鲍勃·切斯布鲁格，英特尔高级解决方案架构师， 领英

会议概览

在本次会议中，鲍勃首先介绍了他对收集恐龙化石的兴趣，并对英特尔人工智能软件组合进行了概述。

他随后解释了创建恐龙遗址宝藏地图或恐龙骨骼可能性地图的步骤：

  1. 收集数据并创建训练数据（新墨西哥州莫里逊地层的大气照片——美国西部著名的恐龙骨骼床以及发现的小骨骼碎片的 GPS 坐标）
  2. 使用英特尔® PyTorch 扩展训练一个简单的 ResNet 18 模型
  3. 在犹他州的图片上评分模型并创建热图

最后，鲍勃展示了使用恐龙骨骼可能性图在犹他州发现恐龙骨骼的结果。前往 GitHub 仓库获取代码示例，并使用 Intel Extension for PyTorch 尝试示例。

在这里观看完整视频录像 ，下载演示文稿 。更多详情请参阅此博客 。

关于演讲者

鲍勃·切斯布鲁格在软件开发和 AI 解决方案工程领域拥有超过三十年的行业经验，为财富 100 强公司和国家级实验室工作。他还是一名业余爱好者，已在野外寻找恐龙骨骼超过 800 英里和 1000 小时。他和他的儿子们在新墨西哥州发现了已知侏罗纪时期唯一的鳄鱼化石，他们还发现了 2000 多个骨骼地点并记录在博物馆中，并在新墨西哥州描述了一个新的骨床。

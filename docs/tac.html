PyTorch 基金会技术顾问委员会

PyTorch 基金会的技术顾问委员会（TAC）为技术沟通、领导和协作提供了一个论坛。委员会成员是 PyTorch 基金会的成员。

TAC 每月举行一次公开会议，任何社区成员都可以参加。委员会在技术主题上提供思想领导，知识分享，并与其他技术专家讨论问题的论坛。

TAC 成员

布莱恩·格兰杰，亚马逊网络服务

布莱恩·格兰杰是亚马逊网络服务的资深技术专家，同时也是加州圣路易斯奥比斯波加州州立理工大学物理学和数据科学教授。他在用户体验设计、工程以及科学计算、数据科学、机器学习和数据可视化工具的交汇处工作。布莱恩是 Jupyter 项目的共同创始人兼领导者，Altair 统计可视化项目的共同创始人，以及 Python 中基于 ZMQ 消息传递的 PyZMQ 项目的创造者。

杰夫·戴利，AMD

杰夫·戴利是 AMD 的 Fellow，同时也是支持 PyTorch 和 onnxruntime 在 AMD GPU 上运行的机器学习软件工程团队的负责人。他喜欢将开源软件交付给社区，以应对快速变化的机器学习领域的挑战。在过去的五年中，他一直为 PyTorch 的核心以及其扩展库做出贡献。他持续的贡献使他获得了 Linux Foundation PyTorch 奖“长期贡献卓越奖”，这是 PyTorch 历史上的第一个奖项。尽管他没有成为维护者，但杰夫是一位值得信赖的贡献者。杰夫的技术领导力是 PyTorch 能够在 AMD GPU 上无需任何代码修改即可运行的原因之一。除了 PyTorch 的技术贡献外，杰夫还是 PyTorch 基金会技术顾问委员会的 AMD 代表。

米洛斯·普佐维奇，Arm

米洛斯·普佐维奇是 Arm 的技术总监，在那里他致力于加速机器学习框架，如 PyTorch 在 AArch64 上的应用。在过去，他致力于设计和开发用于边缘设备和云端的快速开发和部署新型神经模型的基础设施，这些模型是通过半监督方法训练的。他还对通过机器学习、代码生成、优化和验证不同架构的高层模型来优化应用程序感兴趣。米洛斯在剑桥大学获得计算机科学博士学位，他的论文是关于动态多核调度的硬件/软件接口，并在伦敦帝国理工学院获得数学和计算机科学一等荣誉学士学位。

沙乌欣·扎希拉扎米，谷歌

沙乌欣拥有控制工程博士学位和应用数学学士学位。他目前领导谷歌的 Cloud TPU 机器学习团队，该团队负责机器学习框架和第三方生态系统，包括开发 PyTorch/XLA 的 PyTorch 团队。

姜一昆，华为

Mudhakar Srivatsa, IBM

Mudhakar Srivatsa 是 IBM TJ Watson 研究中心的杰出工程师，负责在多个 AI 加速器上对生成式 AI 模型的推理优化。https://research.ibm.com/people/mudhakar-srivatsa

Jiong Gong, Intel (TAC 副主席)

Jiong Gong 是英特尔的一名软件架构师和首席工程师，专注于深度学习框架及其英特尔加速扩展的优化。他之前在 Caffe 和 Caffe2 上工作，目前专注于 PyTorch 和 PyTorch 的英特尔扩展（IPEX）。Jiong 负责整个软件栈的架构设计，包括前端 API、算子优化、图编译器和加速器库设计。作为 PyTorch 社区的活跃贡献者和 PyTorch CPU 模块的维护者之一，他在推进深度学习技术方面发挥着关键作用。Jiong 还在深度学习压缩方面是专家，为英特尔低精度深度学习技术，如 DL Boost 做出了重大贡献。

卢卡·安蒂加，Lightning AI (TAC 主席)

卢卡自 2022 年起担任 Lightning 的 CTO，是 PyTorch 核心的早期贡献者，并合著了《使用 PyTorch 进行深度学习》（由 Manning 出版社出版）。他最初是一名生物工程研究员，后来共同创立了 Orobix 公司，该公司专注于构建和部署 AI 到生产环境中。

格雷戈里·查南，Meta

索乌米特·钦塔拉，Meta

Soumith Chintala 是一位专注于人工智能和机器人的科学家-工程师，领导了 PyTorch、DCGAN 和 Torch-7 等有影响力的 AI 工作；这些工作被包括 NASA、Meta、Google、Tesla、Microsoft、Disney、Genentech 在内的多家顶级机构以及斯坦福、哈佛、牛津和麻省理工学院等顶级大学采用，并纳入了这些大学的课程。他目前领导 Meta 的 PyTorch 和其他 AI 项目，是纽约大学的客座教授，并在多家机构担任顾问角色。

Xavier Dupré，微软

1999 年毕业于 ENSAE，2004 年获得博士学位，Xavier Dupré开始在 A2iA 公司工作，该公司专注于支票自动读取和手写识别。在金融领域短暂工作后，他于 2008 年加入雅虎，负责通过实现适用于所有语言的统计算法来解决搜索查询重写问题。2010 年，Xavier 加入微软，参与本地搜索引擎的开发。他参与了黄页和必应之间的合作。Xavier 在微软的搜索引擎必应上解决了非常大规模的问题。现在，他正在从事 Azure 机器学习的工作。同时，Xavier Dupré自 2001 年以来一直在 ENSAE 教授编程。2014 年，课程扩展到机器学习和与大数据相关联的技术，包括通过微软法国和 ENSAE 之间的合作而引入的 Azure。最近，Xavier 通过黑客马拉松（2015 年 11 月微软-ENSAE-红十字会黑客马拉松 - 视频 - 文章）、通过学生项目或编码小吃等方式探索了新的教学方法。

Piotr Bialecki，NVIDIA

皮奥特于 2019 年加入 NVIDIA 的 PyTorch 团队，目前负责管理该团队。他推动 NVIDIA 在维护和推进 PyTorch 的 CUDA 后端方面的努力，并在 2023 年因其在 PyTorch 讨论板上的社区贡献而获得 PyTorch 超级英雄奖。作为核心维护者，他还专注于 PyTorch 的长期愿景和发展。

    PyTorch 移动端

    在边缘设备上执行机器学习模型的需求日益增长，以减少延迟、保护隐私并启用新的交互式用例。

    PyTorch Mobile 运行时 Beta 版本允许您在 PyTorch 生态系统中无缝地从训练模型过渡到部署，同时保持完全一致。它提供了一个端到端的工作流程，简化了移动设备从研究到生产环境的过程。此外，它通过联邦学习技术为隐私保护特性铺平了道路。

    PyTorch Mobile 目前处于 Beta 阶段，已经广泛应用于大规模生产。一旦 API 锁定，它将很快作为稳定版本发布。

    关键特性

    • 支持苹果 iOS、 安卓 Android 和 Linux
    • 提供覆盖将机器学习融入移动应用所需的常见预处理和集成任务的 API
    • 支持通过 TorchScript IR 进行跟踪和脚本编写
    • 支持 XNNPACK 浮点内核库用于 Arm CPU
    • 集成 QNNPACK 用于 8 位量化内核。包括对每通道量化、动态量化等功能的支持
    • 提供一个高效的移动解释器，适用于 Android 和 iOS。还支持根据用户应用所需的操作进行构建级别优化和选择性编译（即，应用的最终二进制大小由应用实际需要的操作决定）。
    • 通过 optimize_for_mobile 流线化模型优化
    • 将很快在 Beta 版本中提供对 GPU、DSP 和 NPU 等硬件后端的支持

    原型

    我们已在原型中推出了以下功能，这些功能可在 PyTorch 夜间版本中找到，并期待您在 PyTorch 论坛上提供反馈：

    • 通过 Metal 在 iOS 上支持 GPU
    • 通过 Vulkan 在 Android 上支持 GPU
    • 在 Android 上通过 Google NNAPI 支持 DSP 和 NPU

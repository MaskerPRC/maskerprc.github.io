前向模式自动微分

前向模式自动微分（基于“双张量”）的核心逻辑现在已集成到 PyTorch 中。所有用于操作此类张量、代码生成和视图处理的 API 已在 master（1.9.0a0） 中。下个月将添加 Gradcheck 和一组公式；今年晚些时候将实现所有 PyTorch 函数、自定义 Autograd 函数和更高阶梯度的全面支持。了解更多关于此信息或与 @albanD 在相应的 RFC 上分享您的反馈。

使复杂动词变位变得懒散

PR #54987 使复杂张量的变位操作返回一个具有特殊 is_conj() 位反转的视图。除了通过不创建完整张量来节省内存外，如果后续操作可以直接处理变位输入，这还可能带来速度提升。对于此类操作（如 gemm），会向底层 API 传递一个标志；对于其他操作，则在传递给操作之前将变位具体化。

torch.use_deterministic_algorithms 已稳定

torch.use_deterministic_algorithms() ( 文档 ) 在 master (1.9.0a0) 中已稳定。如果为 True，则标志将非确定性行为切换到可用的确定性行为实现，如果不可用则抛出 RuntimeError。

torch.linalg 和 torch.special


torch.linalg 现已稳定；该模块与 NumPy 的 np.linalg 线性代数函数保持一致性。 torch.special（测试版）包含 scipy.special 中的函数。如果您想为 torch.special 贡献函数，请查看此 跟踪问题 。如果您想添加列表中尚未出现的函数，请在跟踪问题中说明您的用例以及为什么应该添加该函数。

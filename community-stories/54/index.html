本文介绍了 ChemicalX，这是一个基于 PyTorch 的深度学习库，旨在提供一系列最先进的模型来解决药物配对评分任务。该库的主要目标是使深度药物配对评分模型对机器学习研究人员和从业者来说易于访问。ChemicalX 的设计采用了这种 http URL 设计，它重用了 PyTorch 生态系统中的现有高级模型训练工具、几何深度学习和深度化学层。我们的系统为最终用户提供神经网络层、自定义配对评分架构、数据加载器和批量迭代器。我们通过示例代码片段和案例研究来展示这些功能，以突出 ChemicalX 的特点。一系列针对现实世界药物-药物相互作用、多药副作用和组合协同预测任务的实验表明，ChemicalX 中可用的模型在解决配对评分任务方面是有效的。最后，我们展示了 ChemicalX 可用于在具有数十万个化合物的大型药物配对数据集上使用通用硬件训练和评分机器学习模型。

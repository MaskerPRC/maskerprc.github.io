如何加速 PyTorch Geometric 在 Intel® CPU 上的运行

由英特尔提供

概述

英特尔 PyTorch 团队一直与 PyTorch Geometric（PyG）社区合作，为图神经网络（GNN）和 PyG 工作负载提供 CPU 性能优化。在 PyTorch 2.0 版本中，引入了多项关键优化，以提升 CPU 上 GNN 训练和推理性能。开发者和研究人员现在可以利用英特尔 AI/ML 框架优化 ，实现模型训练和推理的显著加速，从而解锁直接使用 PyG 进行 GNN 工作流的能力。

在本文中，我们将深入探讨如何通过使用 PyTorch 2.0 的旗舰功能 torch.compile 来优化 PyG 的性能，以实现训练和推理的优化。

消息传递范式

消息传递是指节点通过向彼此发送消息与各自的邻居交换信息的过程。在 PyG 中，消息传递过程可以概括为三个步骤：

  1. 收集 : 收集相邻节点和边的边缘级信息。
  2. 应用 : 使用用户定义函数（UDFs）更新收集到的信息。
  3. 散列 : 通过特定的聚合函数（如求和、平均值或最大值）汇总到节点级信息。

图 1: 消息传递范式（来源：Matthias Fey）

图的邻接矩阵的存储格式与消息传递性能高度相关，它记录了节点对之间的连接方式。存储格式的两种方法是：

  • COO（坐标格式）邻接矩阵： 图数据以二维张量的形式物理存储，形状为 [2, num_edges]，映射源节点和目标节点的每个连接。性能瓶颈在于 scatter-reduce 操作。
  • CSR（压缩稀疏行）邻接矩阵： 与 COO 格式类似，但压缩了行索引。这种格式允许更高效的行访问和更快的稀疏矩阵-矩阵乘法（SpMM）。性能瓶颈在于稀疏矩阵相关的减少操作。

Scatter-Reduce

散射-减少的模式本质上是并行的，它使用由 index 指定的条目中的 src 张量的值来更新 self 张量的值。理想情况下，在外部维度上并行化将是最高效的。然而，直接并行化会导致写冲突，因为不同的线程可能会同时尝试更新相同的条目。

图 2：散射-减少及其优化方案（来源：马明飞）

为了优化这个内核，我们使用排序和减少：

  • 排序： 使用并行基数排序按升序对 index 张量进行排序，以便管理指向 self 张量中相同条目的索引在同一个线程中。
  • 减少： 在自身的外维并行，并对每个索引的 src 条目进行向量化减少。

在其训练过程中的反向路径（即收集）中，不需要排序，因为其内存访问模式不会导致任何写入冲突。

SpMM-Reduce

稀疏矩阵-矩阵减少是 GNN 中的一个基本算子，其中 A 是 CSR 格式的稀疏邻接矩阵，B 是一个密集特征矩阵，其中减少类型可以是求和 、 平均值或最大值 。

图 3：SpMM 优化方案（来源：马明飞）

在优化此内核时最大的挑战是如何在稀疏矩阵 A 的行上并行化时平衡线程负载。矩阵 A 中的每一行对应一个节点，其连接数可能相差很大；这导致了线程负载不均衡。解决此类问题的一种技术是在线程分区之前进行负载扫描。除此之外，还引入了其他技术来进一步利用 CPU 性能，例如向量化、展开和分块。

这些优化是通过 torch.sparse.mm 使用 amax、amin、mean、sum 的 reduce 标志来完成的。

性能提升：最高可达4.1倍加速

我们在 pytorch_geometric/benchmark 和 Open Graph Benchmark (OGB) 中收集了推理和训练的基准性能，以展示上述方法在 Intel® Xeon® Platinum 8380 处理器上的性能提升。

从基准测试结果来看，我们在 PyTorch 和 PyG 中的优化实现了 1.1 倍至 4.1 倍的速度提升 ，提高了推理和训练效率。

PyG 的 torch.compile

PyTorch2.0 的旗舰功能 torch.compile 与 PyG 2.3 版本完全兼容，借助 TorchInductor C++/OpenMP 后端为 CPU 带来的额外加速，在 PyG 模型推理/训练中相对于命令式模式实现了进一步的加速。特别是，在基于 Intel Xeon Platinum 8380 处理器的基本 GNN 模型上，模型训练时测得 3.0 倍至 5.4 倍的性能提升 。

图 4：使用 Torch Compile 的性能加速

Torch.compile 可以将消息传递的多个阶段融合成一个内核，从而由于节省内存带宽而提供显著的加速。请参阅此 PyTorch 几何教程以获取更多支持。

请注意 ，PyG 中的 torch.compile 处于测试版模式，并且正在积极开发中。目前，一些功能还不能无缝协同工作，例如 torch.compile(model, dynamic=True)，但 Intel 正在修复这些问题。

结论与未来工作

在本博客中，我们介绍了 PyTorch 2.0 在 CPU 上包含的 GNN 性能优化。我们正在与 PyG 社区紧密合作，进行未来的优化工作，这些工作将重点从 torch.compile、稀疏优化和分布式训练进行深入优化。

2021年9月8日

宣布 PyTorch 年度黑客马拉松 2021

由 PyTorch 团队编写

我们非常激动地宣布 2021 年 PyTorch 年度黑客马拉松！今年，我们致力于支持社区创造创新的 PyTorch 工具、库和应用。2021 年是我们举办这个黑客马拉松的第三年，我们欢迎您加入 PyTorch 社区，将您的机器学习技能付诸实践。提交开始于 9 月 8 日，结束于 11 月 3 日。祝大家好运！

提交类别

您可以将您的 PyTorch 项目提交到三个类别中：

  • PyTorch 负责任的人工智能开发工具和库 - 开发一个有助于负责任地开发 AI 模型和应用的 AI 开发工具或库。这些工具、库和应用程序需要支持研究人员或开发人员在数据收集、模型训练、模型验证、推理、监控等整个机器学习开发过程中考虑公平性、安全性和隐私性。

  • 由 PyTorch 驱动的 Web 和移动应用程序 - 使用 Web、移动界面和/或嵌入式设备构建应用程序，以便最终用户可以与之交互。提交必须基于 PyTorch 构建或使用基于 PyTorch 的库，如 torchvision、torchtext 和 fast.ai。

  • PyTorch 开发者工具和库 - 构建一个创意、实用且实现良好的工具或库，以提高 PyTorch 研究人员和开发者的生产力和效率。提交必须是一个使用 PyTorch 或基于 PyTorch 的库构建的机器学习算法、模型或应用程序。

奖项

提交将根据想法的质量、原创性、实现和潜在影响进行评判。

  • 每个黑客松类别的第一名将获得 5000 美元现金，以及与 PyTorch 开发团队的 30 分钟通话。

  • 第二名将获得 3000 美元。

  • 第三名将获得 2000 美元。

所有获奖者还将有机会创建博客文章，这些文章将在 PyTorch 渠道中展示，并获得专属的 GitHub 徽章。每个类别还将授予前三个得分最高的参赛作品荣誉提名，并每人获得 1000 美元。

云计算积分

从亚马逊云服务或谷歌云请求 100 美元的积分以支付您的计算费用。请允许 3 个工作日来审查您的请求。积分将提供给已验证的注册者，直到供应耗尽。更多信息请见 https://pytorch2021.devpost.com/details/sponsors。

2020年获奖项目

DeMask 在 PyTorch 开发者工具类别中荣获第一名。DeMask 是一个端到端模型，用于增强佩戴口罩时的语音，它使用基于 PyTorch 的音频分离工具包 Asteroid 构建。

Q&Aid 在 PyTorch 驱动的 Web/移动应用程序类别中荣获第一名。Q&Aid 是一个基于 PyTorch 核心算法和模型的创新性医疗保健聊天机器人，旨在辅助医疗诊断并促进患者与医生之间的沟通。

FairTorch 在 PyTorch 负责任人工智能开发工具类别中荣获第一名。FairTorch 是一个 PyTorch 公平性库，允许开发者通过添加几行代码来对模型添加约束，从而在子组之间平等化指标。

如何加入

如果您有兴趣参加今年的 PyTorch 黑客马拉松，请在此注册：http://pytorch2021.devpost.com。

2020年7月28日

推出原生 PyTorch 自动混合精度，在 NVIDIA GPU 上实现更快训练

黄梦迪，切坦·特库尔，迈克尔·卡里利

大多数深度学习框架，包括 PyTorch，默认使用 32 位浮点数（FP32）算术进行训练。然而，这并非实现许多深度学习模型完全精度的必要条件。2017 年，NVIDIA 研究人员开发了一种混合精度训练的方法，该方法在训练网络时将单精度 （FP32）与半精度（例如 FP16）格式相结合，在相同的超参数下实现了与 FP32 训练相同的精度，并在 NVIDIA GPU 上提供了额外的性能优势：

  • 更短的训练时间；
  • 更低的内存需求，使得能够使用更大的批量大小、更大的模型或更大的输入。

为了简化研究人员和从业者进行混合精度训练的用户体验，NVIDIA 于 2018 年开发了 Apex，这是一个轻量级的 PyTorch 扩展，具有自动混合精度 （AMP）功能。该功能能够自动将某些 GPU 操作从 FP32 精度转换为混合精度，从而在保持准确性的同时提高性能。

对于 PyTorch 1.6 版本，NVIDIA 和 Facebook 的开发者将混合精度功能移入 PyTorch 核心作为 AMP 包，即 torch.cuda.amp。与 apex.amp 相比，torch.cuda.amp 更加灵活直观。以下是一些 apex.amp 已知的痛点，而 torch.cuda.amp 已经能够解决的：

  • 保证与 PyTorch 版本兼容，因为它本是 PyTorch 的一部分
  • 无需构建扩展
  • Windows 支持
  • 检查点 保存/恢复 的位精度
  • 数据并行 和进程内模型并行（尽管我们仍然推荐每个进程一个 GPU 的 torch.nn.DistributedDataParallel 作为最高效的方法）
  • 梯度惩罚 （双重反向）
  • torch.cuda.amp.autocast() 在未启用该功能的区域外没有效果，因此它应该能够轻松处理以前在多个调用 apex.amp.initialize()（包括 交叉验证 ）时遇到的问题。同一脚本中的多次收敛运行应各自使用一个新的 GradScaler 实例 ，但由于 GradScalers 轻量级且自包含，所以这不会成为问题。
  • 稀疏梯度支持

随着 AMP 被添加到 PyTorch 核心，我们已经开始弃用 apex.amp. 的过程。我们将 apex.amp 转移到维护模式，并将支持使用 apex.amp 的客户。然而，我们强烈建议 apex.amp 客户过渡到使用来自 PyTorch 核心的 torch.cuda.amp。

示例教程

请参阅官方文档了解使用方法：

  • https://pytorch.org/docs/stable/amp.html
  • https://pytorch.org/docs/stable/notes/amp_examples.html

示例：

import torch
# Creates once at the beginning of training
scaler = torch.cuda.amp.GradScaler()

for data, label in data_iter:
   optimizer.zero_grad()
   # Casts operations to mixed precision
   with torch.cuda.amp.autocast():
      loss = model(data)

   # Scales the loss, and calls backward()
   # to create scaled gradients
   scaler.scale(loss).backward()

   # Unscales gradients and calls
   # or skips optimizer.step()
   scaler.step(optimizer)

   # Updates the scale for next iteration
   scaler.update()

性能基准

在本节中，我们讨论了使用 AMP 在最新 NVIDIA GPU A100 和上一代 V100 GPU 上进行的混合精度训练的准确性和性能。混合精度性能与在 NGC 的 NVIDIA pytorch:20.06-py3 容器中运行深度学习工作负载时的 FP32 性能进行了比较。

准确度：AMP (FP16), FP32

使用 AMP 进行深度学习训练的优势在于，模型在提供改进的训练性能的同时，收敛到相似的最终准确度。为了说明这一点，对于 Resnet 50 v1.5 训练 ，我们看到了以下准确度结果，其中数值越高越好。请注意，以下准确度数值是样本数值，受运行到运行变化的影响，变化幅度可达 0.4%。其他模型（包括 BERT、Transformer、ResNeXt-101、Mask-RCNN、DLRM）的准确度数值可以在 NVIDIA 深度学习示例 Github 找到。

NVIDIA V100 上的 FP16 与 V100 上的 FP32 对比

AMP 与 FP16 是 V100 上深度学习训练中最具性能的选项。在表 1 中，我们可以观察到，对于各种模型，V100 上的 AMP 相对于 V100 上的 FP32 提供了 1.5 倍到 5.5 倍的加速，同时达到相同的最终精度。

图 2.在 NVIDIA 8xV100 上混合精度训练的性能与在 8xV100 GPU 上 FP32 训练的性能对比。柱状图表示 V100 AMP 相对于 V100 FP32 的加速因子。数值越高越好。

NVIDIA A100 上的 FP16 与 V100 上的 FP16

AMP 与 FP16 仍然是 A100 上深度学习训练中最具性能的选项。在图 3 中，我们可以观察到，对于各种模型，A100 上的 AMP 相对于 V100 上的 AMP 提供了 1.3 倍到 2.5 倍的加速，同时达到相同的最终精度。

图 3. 在 NVIDIA 8xA100 与 8xV100 GPU 上混合精度训练的性能。柱状图表示 A100 相对于 V100 的加速因子。数值越高越好。

呼吁行动

AMP 为 Nvidia Tensor Core GPU 上的深度学习训练工作负载提供了健康的速度提升，尤其是在最新的 Ampere 代 A100 GPU 上。您可以开始尝试使用 A100、V100、T4 以及其他 NVIDIA 深度学习示例中可用的 AMP 启用模型和模型脚本。从 PyTorch NGC 容器的 20.06 版本开始，NVIDIA PyTorch 支持原生 AMP。我们强烈建议现有的 apex.amp 用户过渡到使用 PyTorch Core 中的 torch.cuda.amp，该 Core 可在最新的 PyTorch 1.6 版本中找到。

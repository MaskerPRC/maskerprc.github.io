2023 年 6 月 7 日

加入 PyTorch 基金会：会员招募现已开启

由 PyTorch 团队

2022 年 9 月，我们将 Meta 的 PyTorch 引入 Linux Foundation，并与 AMD、亚马逊网络服务（AWS）、谷歌、Meta、微软和英伟达共同成立了 PyTorch 基金会。

自那时以来，我们见证了显著的增长，包括所有存储库提交量增长了 39%，独特贡献者增长了 27%，社区贡献增长了 12%，这一切都在过去 90 天内发生！我们对创始成员推动基金会向前发展所给予的支持表示感激。

今天，我们宣布 PyTorch 基金会现在对外开放会员资格。

成为 PyTorch 基金会的成员，您将能够访问资源，这些资源使您能够成为稳定、安全且持久代码库的守护者。您可以参与培训和认证项目、本地和区域活动、开源开发者工具、学术研究和指南，以帮助新用户和贡献者拥有高效的使用体验。

PyTorch 基金会旨在帮助最终用户导航 PyTorch 生态系统，招募人才，并成功采用 PyTorch 和支持开源人工智能技术。

为何加入会员

成为 PyTorch 基金会的一员，您将有机会与行业同仁一起共同构建端到端机器学习框架的未来。

会员权益包括：

  • 通过让您的团队与其他行业领导者沉浸式交流，为您的组织产品获得技术动力和洞察。
  • 影响技术优先级、方法和代码。
  • 通过资助项目及其社区依赖的项目和服务的计划，支持 PyTorch 项目社区。
  • 与 PyTorch 项目生态系统互动，与同行建立联系，并共同构建和维护一个引人入胜且强大的 PyTorch 生态系统。
  • 提供思想领导力，并参与独特、广泛影响的网络和营销计划，以扩大行业意识，同时 PyTorch 放大成员进步。
  • 保留、吸引和增加工程技能和员工，构建您的创新合作伙伴网络、供应链和客户管道。
  • 作为 PyTorch 社区的活跃成员，您可以深化在本地和行业开发者网络及会议中的参与和领导。

如何加入

商业组织被邀请申请普通会员，而非营利机构和学术机构则鼓励申请副会员。

首席会员

机构可提交申请，以成为首席会员的考虑对象。首席会员是最高级别。他们将在 PTF 治理委员会的任何子委员会或活动中任命一名投票代表，并在会员展示（包括网站、景观和营销材料）中获得突出位置，享有 PyTorch 在线课程的独家直播研讨会以及“一般”会员所包含的一切。年费为 150,000 美元加 LF 银色会员资格。

普通会员

普通会员将参与所有营销、社区和思想领导力机会，以及活动赞助和培训课程的折扣。普通会员还有机会被考虑担任 PTF 董事会职位。年费取决于您机构的规模。更多详情请见此处。

协作者会员

协作者会员可以自由加入，并将获得 PyTorch 基金会团队的支持和参与机会。更多信息请在此处查看。

AWS

“AWS 坚信 PyTorch 基金会通过开放协作开发 AI 和深度学习工具的使命。我们的客户每天都在 AWS 上使用 PyTorch 构建、训练和部署机器学习模型。通过我们的参与，AWS 正在支持创新，并帮助让开源工具更易于我们的客户和更广泛的社区使用。”

Google

“人工智能革命正在到来，它建立在 PyTorch 之上。随着 ChatGPT 和 Stable Diffusion 等新应用在 PyTorch 上构建，生成式 AI 的浪潮继续在社会各个领域感受到。作为谷歌，我们很高兴成为 PyTorch 基金会的创始成员，我们期待着与 AI 领域的其他领导者紧密合作，共同推动这个令人惊叹且富有创新精神的社区的发展。”

Meta

“Meta 在 AI 工作中一直将开放科学作为核心，PyTorch 也不例外。PyTorch 从头开始就采用了开源、以社区为先的哲学。我们将 PyTorch 过渡到 PyTorch 基金会，因为我们相信这种方法能够使我们在构建和部署新的系统方面取得最快的进展，这些系统将解决现实世界的需求，并回答关于智能本质的基本问题。在 PyTorch 基金会的支持下，整个 AI 社区将能够以无数令人兴奋的新方式推动该领域的发展。”

微软

“微软对 PyTorch 充满信心，能够成为 PyTorch 基金会的创始成员是一种荣誉。内部，我们广泛使用 PyTorch，其结果是 Azure Container for PyTorch，它为 PyTorch 开发提供了深度优化，包括 ONNX Runtime、DeepSpeed 和 Nebula，以大幅降低训练成本并加速 Azure Machine Learning 上的训练时间。作为我们持续致力于开源机器学习平台的承诺的一部分，我们期待与行业领导者合作，继续为 PyTorch 的发展做出贡献。”

英伟达

“作为领先的基于 Python 的 AI 框架，PyTorch 对于LLMs和 GenAI 的开发至关重要。英伟达的目标是作为 PyTorch 基金会的一部分，深化与开源 AI 社区的协作，并帮助构建下一波先进、节能且成本效益高的应用，利用加速计算。”

2024年10月25日

PyTorch 2.5 现已支持 Intel GPU

由英特尔 PyTorch 团队提供

PyTorch® 2.5 现在支持英特尔 GPU，提供了对英特尔 GPU 的改进功能性能，包括英特尔® Arc™独立显卡 、 英特尔® Core™ Ultra 处理器内置的英特尔® Arc™图形和英特尔®数据中心 GPU Max 系列 。此集成将英特尔 GPU 和 SYCL*软件堆栈纳入官方 PyTorch 堆栈，确保一致的用户体验并支持更广泛的 AI 应用场景，特别是在 AI PC 领域。

为英特尔 GPU 构建和使用的开发人员和客户将获得更好的用户体验，因为他们可以直接从本机 PyTorch 获得持续软件支持、统一的软件分发和一致的产品发布时间。

此外，英特尔 GPU 支持为用户提供了更多选择。现在 PyTorch 在前后端都提供了统一的 GPU 编程范式。开发者现在可以以最小的编码工作量在英特尔 GPU 上运行和部署工作负载。

英特尔 GPU 支持概述

PyTorch 中的英特尔 GPU 支持提供了 PyTorch 内置前端中的 eager 模式和支持 graph 模式。eager 模式现在已实现常用的 Aten 算子与 SYCL 编程语言。graph 模式（torch.compile）现在已启用英特尔 GPU 后端以实现针对英特尔 GPU 的优化并集成 Triton。

已将英特尔 GPU 支持的必要组件添加到 PyTorch 中，包括运行时、Aten 算子、oneDNN、TorchInductor、Triton 以及英特尔 GPU 工具链集成。同时，为了准备 PyTorch 2.6 的发布，量化（quantization）和分布式（distributed）正在积极开发中。

特性

除了为 Intel®客户端 GPU 和 Intel®数据中心 GPU Max 系列提供推理和训练的关键功能外，PyTorch 还保持了与其他硬件相同的用户体验。如果您从 CUDA*迁移代码，可以在进行最小代码更改（将设备名从 cuda 更改为 xpu）的情况下，在 Intel GPU 上运行现有的应用程序代码。例如：

# CUDA 代码
张量 =torch.tensor([1.0, 2.0]).to(“cuda”)

# Intel GPU 代码
张量 =torch.tensor([1.0, 2.0]).to(“xpu”)

PyTorch 2.5 功能，使用 Intel GPU 包括：

  • 推理和训练工作流程。
  • 增强 torch.compile 和 eager 模式功能（更多操作），以及性能提升，并在 eager 和 compile 模式下完全运行三个 Dynamo Hugging Face*、TIMM* 和 TorchBench* 基准测试。
  • 数据类型，如 FP32、BF16、FP16 和自动混合精度（AMP）。
  • 支持在 Intel®客户端 GPU 和 Intel®数据中心 GPU Max 系列上运行。
  • 支持 Linux（Ubuntu、SUSE Linux 和 Red Hat Linux）以及 Windows 10/11 操作系统。

开始使用

从入门指南获取环境设置、PIP wheels 安装和示例教程，了解如何在 Intel®客户端 GPU 和 Intel®数据中心 GPU Max 系列上操作。通过 PyTorch PIP wheels 安装的夜间和预览二进制版本，可以体验 Intel GPU 的支持。

  • 尝试通过英特尔® Arc™ 图形家族（代号 DG2）、英特尔® Core™ Ultra 处理器家族（代号 Meteor Lake）以及英特尔® Core™ Ultra 移动处理器家族（代号 Lunar Lake）体验英特尔® 客户端 GPU。

  • 尝试通过英特尔® Tiber™ AI 云体验英特尔数据中心 GPU Max 系列。

    1. 想要了解如何创建免费标准账户，请参阅开始使用 。然后执行以下操作：

      • 登录到云控制台 。

      • 从培训   部分，打开 PyTorch on Intel® GPUs 笔记本并点击“启动 Jupyter Notebook。”

      • 确保笔记本选择的是 PyTorch 2.5 内核。

性能

Intel GPU 在 PyTorch 上的性能持续优化，以达到在三个 Dynamo Hugging Face、TIMM 和 TorchBench 基准测试中 eager 和 compile 模式下的良好结果。

使用 Intel®数据中心 GPU Max 系列 1100 单卡在 PyTorch Dynamo Benchmarking Suite 上测量的最新性能数据，如图 1 所示，FP16/BF16 在 eager 模式下相对于 FP32 有显著的加速比，如图 2 所示，Torch.compile 模式相对于 eager 模式的加速比。推理和训练都达到了类似的显著改进。

图 2：FP16/BF16 相对于 FP32 eager 模式的性能提升

图 3：torch.compile 相对于 eager 模式的性能提升

摘要

英特尔 GPU 在 PyTorch 2.5 中，将英特尔®客户端 GPU（内置英特尔® Arc™图形的英特尔® Core™ Ultra 处理器和用于 dGPU 部分的英特尔® Arc™图形）以及英特尔®数据中心 GPU Max 系列引入 PyTorch 生态系统，以加速 AI 工作负载。特别是，客户端 GPU 被添加到支持 GPU 的列表中，用于 Windows 和 Linux 环境下的 AI PC 使用场景。

我们热烈欢迎社区评估并提供反馈，关于这些针对英特尔 GPU 在 PyTorch 上的支持的增强。

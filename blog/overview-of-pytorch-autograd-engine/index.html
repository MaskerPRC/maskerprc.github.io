PyTorch 自动微分引擎概述

由 Preferred Networks，Inc.提供

本博客文章基于 PyTorch 版本 1.8 编写，尽管它也适用于较旧版本，因为大部分机制都保持不变。

为了帮助理解这里解释的概念，建议您阅读由 @ezyang 撰写的精彩博客文章：PyTorch 内部机制 ，如果您不熟悉 PyTorch 架构组件，如 ATen 或 c10d。

什么是 autograd？

背景

PyTorch 通过自动微分计算函数相对于输入的梯度。自动微分是一种技术，给定一个计算图，可以计算输入的梯度。自动微分可以有两种不同的方式；正向模式和反向模式。正向模式意味着我们在计算函数结果的同时计算梯度，而反向模式则需要我们首先评估函数，然后从输出开始计算梯度。虽然两种模式都有其优缺点，但由于输出的数量少于输入的数量，反向模式成为了事实上的选择，这允许更高效的计算。请参阅[3]了解更多信息。

自动微分依赖于经典的微积分公式，即链式法则。链式法则允许我们通过拆分和重新组合来计算非常复杂的导数。

从严格意义上讲，给定一个复合函数 ，我们可以计算其导数作为 。这个结果使得自动微分得以工作。通过结合组成较大函数（如神经网络）的简单函数的导数，可以计算给定点的梯度确切值，而不是依赖于数值近似，这需要多次扰动输入来获得值。

形式上，我们在这里所做的是，PyTorch 自动微分引擎也这样做，就是计算雅可比-向量积（Jvp），以计算模型参数的梯度，因为模型参数和输入都是向量。

雅可比-向量积

当我们计算一个向量值函数 （输入和输出都是向量的函数）的梯度时，我们实际上是在构造一个雅可比矩阵。

多亏了链式法则，将函数 的雅可比矩阵与标量函数 的先前计算梯度向量 相乘，可以得到标量输出相对于向量值函数输入的梯度 。

以下以 Python 语法为例，说明链式法则的应用。


def f(x1, x2):
a = x1 * x2
y1 = log(a)
y2 = sin(x2)
return (y1, y2)

def g(y1, y2):
return y1 * y2

结果与我们的手算雅可比-向量积相同！然而，PyTorch 从未构建矩阵，因为矩阵可能会变得过大，而是创建了一个操作图，在反向遍历的同时应用了定义在 tools/autograd/derivatives.yaml 中的雅可比-向量积。

遍历图

每当 PyTorch 执行一个操作时，自动微分引擎都会构建一个反向遍历的图。反向模式自动微分首先在末尾添加一个标量变量 ，以便 ，正如我们在引言中看到的。这就是我们上面看到的 Jvp 引擎计算中提供的初始梯度值。

在 PyTorch 中，用户在调用反向方法时，会显式地设置初始梯度。

然后，开始计算 Jvp，但从不构建矩阵。相反，当 PyTorch 记录计算图时，会添加执行的前向操作的导数（反向节点）。图 5 显示了之前看到的函数 和 执行产生的反向图。

图5：反向传递扩展的计算图

前向传递完成后，结果被用于反向传递，其中计算图中的导数被执行。基本导数存储在 tools/autograd/derivatives.yaml 文件中，它们不是常规导数，而是它们的 Jvp 版本[3]。它们将原始函数的输入和输出作为参数，以及函数输出相对于最终输出的梯度。通过反复将得到的梯度与图中下一个 Jvp 导数相乘，根据链式法则生成直到输入的梯度。

图6：反向微分中链式法则的应用

图 6 通过展示链式法则来表示这个过程。我们从一个值为 1.0 的值开始，如前所述，这是已经计算出的梯度 ，用绿色突出显示。然后我们移动到图中的下一个节点。在 derivatives.yaml 中注册的反向函数将计算相关的 值，用红色突出显示，并将其乘以 。根据链式法则，这导致 ，这将是当我们处理图中的下一个反向节点时已经计算出的梯度（绿色）。

你可能也注意到了，在图5中，有一个来自两个不同来源的梯度。当两个不同的函数共享一个输入时，对于该输出的梯度会聚合到那个输入上，并且使用该梯度进行的计算不能继续，除非所有路径都已聚合在一起。

让我们看看在 PyTorch 中如何存储导数的一个例子。

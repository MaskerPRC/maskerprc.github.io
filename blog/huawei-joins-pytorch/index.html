2023年10月17日

华为加入 PyTorch 基金会成为高级会员

由 PyTorch 团队

今天，PyTorch 基金会，一个中立的家，为深度学习社区提供一个开源的 PyTorch 框架和生态系统的协作平台，宣布华为成为其高级会员。

华为一直是 PyTorch 生态系统的长期支持者和贡献者，通过发布渐进式多样化的计算，为更多硬件供应商提供了更便捷的 PyTorch 生态系统访问。通过成为高级会员，华为将继续优化 PyTorch，以充分发挥 Ascend 计算能力。

“我们很高兴加入 PyTorch 基金会，并希望与其他会员公司进一步合作，将社区扩展到更广泛的受众，”华为 Ascend 计算业务总裁张迪轩表示，“这一举措对华为、PyTorch 以及更广泛的 AI 生态系统都有益。这也符合我们长期坚持的开放、创新、合作和共享成功的信念，我们相信这将激发全球 AI 社区的新创新。”

华为发布了全智能战略，旨在加速各行业的智能化进程。为了满足人工智能计算需求，华为投资于系统级技术，这一信念的核心是开放硬件和软件，它能够使合作伙伴受益并培养人才。该战略与 PyTorch 基金会的使命相一致，即开发人工智能作为可持续的开源生态系统的一部分，并产生包容性的技术成就。

PyTorch 基金会执行董事艾哈迈德·哈达德表示：“我们很高兴欢迎华为加入 PyTorch 基金会。华为在计算机视觉、自然语言处理、语音识别和其他新兴领域的研究中处于领先地位，并在基础模型领域拥有丰富的经验。我们坚信，我们将从他们的支持和指导中受益。”

作为高级会员，华为获得 PyTorch 基金会管理委员会的一个席位，并将帮助制定政策、章程以及定义 PyTorch 基金会倡议的总体范围、技术愿景和方向的使命和愿景声明。

董事会欢迎华为代表李峰，华为计算开源开发团队负责人。李峰领导着一个活跃且富有创造力的团队，在研发和运营项目中秉承“向上游”的原则，旨在让多样化的计算能力无处不在。

想了解更多关于如何成为 PyTorch 基金会一员的信息，请访问我们的网站 。

关于华为

华为成立于 1987 年，是全球领先的信息与通信技术（ICT）基础设施和智能设备供应商。我们拥有 207,000 名员工，在 170 多个国家和地区运营，为全球超过 30 亿人提供服务。我们致力于将数字带入每个人的生活、每个家庭和每个组织，打造一个全面连接、智能化的世界。

关于 PyTorch 基金会

PyTorch 基金会是一个中立的家，为深度学习社区提供一个合作平台，共同开发开源的 PyTorch 框架和生态系统。PyTorch 基金会由其成员和 PyTorch 开源项目的领先贡献者支持。基金会利用成员和贡献者提供的资源，促进社区讨论和协作。

关于 Linux 基金会

Linux 基金会是全球领先的开放源代码软件、硬件、标准和数据合作之家。Linux 基金会项目对世界基础设施至关重要，包括 Linux、Kubernetes、Node.js、ONAP、PyTorch、RISC-V、SPDX、OpenChain 等。Linux 基金会致力于利用最佳实践，满足贡献者、用户和解决方案提供商的需求，以创建可持续的开放协作模式。欲了解更多信息，请访问 linuxfoundation.org。Linux 基金会已注册商标并使用商标。有关 Linux 基金会的商标列表，请参阅其商标使用页面 。Linux 是林纳斯·托瓦兹的注册商标。

华为成为 PyTorch 基金会 Premier 会员

PyTorch 基金会是深度学习社区在开源 PyTorch 框架和生态系统上进行协作的中立家园，今天宣布华为已作为 Premier 会员加入。

华为长期以来一直是 PyTorch 生态系统的支持者和贡献者，通过推进多样性算力支持与改进，帮助更多厂商后端能够更加轻松地接入 PyTorch 生态，并积极致力于 PyTorch 优化，从而充分释放昇腾的算力。

“通过加入 PyTorch 基金会，我们可以进一步与其他成员公司共同协作，加速 PyTorch 社区的发展。”华为昇腾计算业务总裁张迪煊表示，“我们相信这对华为和 PyTorch 生态系统是互惠互利的，也符合我们长期以来开放创新，协作共赢的开源理念，为全球人工智能社区带来更多的兴奋和创新。”

华为发布全面智能化战略，加速千行万业智能化的转型，持续通过系统级持续创新，坚持硬件开放、软件开源、使能伙伴、发展人才，以满足各行各业多样性的 AI 算力需求。这与 PyTorch 基金会的使命完美契合且相互补充，即通过培育和维持开源生态系统来推动人工智能的发展，并使每个人都能使用这些技术创新。

“华为在计算机视觉、自然语言处理、语音识别等领域进行了广泛的研究，并且在大模型领域也积累了成熟的研究经验。我们相信 PyTorch 基金会将从他们对我们的成员和生态系统的支持中受益匪浅。”PyTorch 基金会执行董事 Ibrahim Haddad 说道。

作为 Premier 会员，华为获得了 PyTorch 基金会董事会的一个席位。董事会通过我们的章程、使命和愿景声明制定政策，描述基金会计划、技术愿景和方向的总体范围。

我们很高兴欢迎华为计算开源业务总经理李永乐加入我们的董事会。李永乐目前负责华为计算产品线开源业务，他领导着一支极具创新又充满活力的技术和运营团队，他们秉持着“Upstream first”的原则，让多样性算力无处不在。

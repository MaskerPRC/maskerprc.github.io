    Android

    使用 HelloWorld 示例快速入门

    HelloWorld 是一个简单的图像分类应用，演示了如何使用 PyTorch Android API。此应用在静态图像上运行 TorchScript 序列化的 TorchVision 预训练 resnet18 模型，该图像作为安卓资源打包在应用内部。

    1. 模型准备

    让我们从模型准备开始。如果你熟悉 PyTorch，你可能已经知道如何训练和保存你的模型。如果你不熟悉，我们将使用一个预训练的图像分类模型（MobileNetV2）。要安装它，请运行以下命令：

    pip install torchvision

    要序列化模型，你可以在 HelloWorld 应用的根目录中使用 python 脚本 ：

    import torch
import torchvision
from torch.utils.mobile_optimizer import optimize_for_mobile

model = torchvision.models.mobilenet_v2(pretrained=True)
model.eval()
example = torch.rand(1, 3, 224, 224)
traced_script_module = torch.jit.trace(model, example)
traced_script_module_optimized = optimize_for_mobile(traced_script_module)
traced_script_module_optimized._save_for_lite_interpreter("app/src/main/assets/model.ptl")

    如果一切顺利，我们应该在安卓应用的资产文件夹中生成我们的模型 - model.ptl。这将被打包进安卓应用作为 asset，并在设备上使用。

    更多关于 TorchScript 的详细信息，您可以在 pytorch.org 上的教程中找到。

    2. 从 GitHub 克隆

    git clone https://github.com/pytorch/android-demo-app.git
cd HelloWorldApp

    如果 Android SDK 和 Android NDK 已经安装，您可以使用以下命令将此应用安装到已连接的安卓设备或模拟器中：


    ./gradlew installDebug

    我们建议您使用 Android Studio 3.5.1+ 打开此项目。目前 PyTorch Android 和演示应用程序使用 Android Gradle 插件版本 3.5.0，该插件仅由 Android Studio 3.5.1 及以上版本支持。使用 Android Studio，您将能够通过 Android Studio UI 安装 Android NDK 和 Android SDK。

    3. Gradle 依赖项

    PyTorch Android 已添加到 HelloWorld 的 gradle 依赖项 中 build.gradle 文件：

    repositories {
    jcenter()
}

dependencies {
    implementation 'org.pytorch:pytorch_android_lite:1.9.0'
    implementation 'org.pytorch:pytorch_android_torchvision:1.9.0'
}

    其中 org.pytorch:pytorch_android 是主要依赖项，包含 PyTorch Android API，以及适用于所有 4 个 Android ABI（armeabi-v7a、arm64-v8a、x86、x86_64）的 libtorch 本地库。在本文档中，您可以找到如何仅针对特定列表的 Android ABI 重新构建它的方法。

    org.pytorch:pytorch_android_torchvision - 额外库，包含将 android.media.Image 和 android.graphics.Bitmap 转换为张量的实用函数。

    4. 从 Android Asset 读取图像

    所有逻辑都在 org.pytorch.helloworld.MainActivity 中发生。首先，我们使用标准的 Android API 将 image.jpg 读取到 android.graphics.Bitmap。

    Bitmap bitmap = BitmapFactory.decodeStream(getAssets().open("image.jpg"));

    5. 加载移动模块

    Module module = Module.load(assetFilePath(this, "model.ptl"));

    org.pytorch.Module 代表 torch::jit::mobile::Module，可以通过指定文件路径的 load 方法加载已序列化到文件的模型。

    6. 准备输入

    Tensor inputTensor = TensorImageUtils.bitmapToFloat32Tensor(bitmap,
    TensorImageUtils.TORCHVISION_NORM_MEAN_RGB, TensorImageUtils.TORCHVISION_NORM_STD_RGB);

    org.pytorch.torchvision.TensorImageUtils 是 org.pytorch:pytorch_android_torchvision 库的一部分。 TensorImageUtils#bitmapToFloat32Tensor 方法使用 torchvision 格式 和 android.graphics.Bitmap 作为源来创建张量。

    所有预训练模型都期望输入图像以相同的方式进行归一化，即形状为 (3 x H x W) 的 3 通道 RGB 图像的 mini-batches，其中 H 和 W 至少为 224。图像必须加载到 [0, 1] 范围内，然后使用 mean = [0.485, 0.456, 0.406] 和 std = [0.229, 0.224, 0.225] 进行归一化。

    inputTensor 的形状为 1x3xHxW，其中 H 和 W 是位图的高度和宽度。

    7. 运行推理

    Tensor outputTensor = module.forward(IValue.from(inputTensor)).toTensor();
float[] scores = outputTensor.getDataAsFloatArray();

    org.pytorch.Module.forward 方法运行加载的模块的 forward 方法，并获取结果为形状为 1x1000 的 org.pytorch.Tensor 输出 Tensor。

    8. 处理结果

    其内容通过 org.pytorch.Tensor.getDataAsFloatArray() 方法检索，该方法返回每个 ImageNet 类分数的 Java 浮点数数组。

    之后，我们只需找到分数最高的索引，并从包含所有 ImageNet 类的 ImageNetClasses.IMAGENET_CLASSES 数组中检索预测的类名。

    float maxScore = -Float.MAX_VALUE;
int maxScoreIdx = -1;
for (int i = 0; i < scores.length; i++) {
  if (scores[i] > maxScore) {
    maxScore = scores[i];
    maxScoreIdx = i;
  }
}
String className = ImageNetClasses.IMAGENET_CLASSES[maxScoreIdx];

    在以下章节中，您可以找到 PyTorch Android API 的详细说明、更大演示应用程序的代码演示、API 的实现细节以及如何自定义和从源代码构建它。

    PyTorch 演示应用程序

    我们还创建了一个更复杂的 PyTorch Android 演示应用程序，该应用程序可以从相机输出进行图像分类，并在相同的 GitHub 仓库中进行文本分类。

    为了获取设备相机输出，它使用了 Android CameraX API。所有与 CameraX 相关的逻辑都被分离到 org.pytorch.demo.vision.AbstractCameraXActivity 类中。

    void setupCameraX() {
    final PreviewConfig previewConfig = new PreviewConfig.Builder().build();
    final Preview preview = new Preview(previewConfig);
    preview.setOnPreviewOutputUpdateListener(output -> mTextureView.setSurfaceTexture(output.getSurfaceTexture()));

    final ImageAnalysisConfig imageAnalysisConfig =
        new ImageAnalysisConfig.Builder()
            .setTargetResolution(new Size(224, 224))
            .setCallbackHandler(mBackgroundHandler)
            .setImageReaderMode(ImageAnalysis.ImageReaderMode.ACQUIRE_LATEST_IMAGE)
            .build();
    final ImageAnalysis imageAnalysis = new ImageAnalysis(imageAnalysisConfig);
    imageAnalysis.setAnalyzer(
        (image, rotationDegrees) -> {
          analyzeImage(image, rotationDegrees);
        });

    CameraX.bindToLifecycle(this, preview, imageAnalysis);
  }

  void analyzeImage(android.media.Image, int rotationDegrees)

    在哪里处理 analyzeImage 方法处理摄像头输出，android.media.Image。

    它使用上述 TensorImageUtils.imageYUV420CenterCropToFloat32Tensor 方法将 android.media.Image 转换为 YUV420 格式的输入张量。

    从模型获取预测分数后，它找到分数最高的前 K 个类别并在 UI 上显示。

    语言处理示例

    另一个例子是基于 LSTM 模型的自然语言处理，该模型在 Reddit 评论数据集上进行了训练。逻辑发生在 TextClassificattionActivity 中。

    结果类名打包在 TorchScript 模型中，并在初始化模块后立即初始化。该模块有一个 get_classes 方法，它返回 List[str]，可以使用方法 Module.runMethod(methodName) 调用：

        mModule = Module.load(moduleFileAbsoluteFilePath);
    IValue getClassesOutput = mModule.runMethod("get_classes");

    返回的 IValue 可以使用 IValue.toList() 转换为 IValue 的 Java 数组，并使用 IValue.toStr() 处理为字符串数组：

        IValue[] classesListIValue = getClassesOutput.toList();
    String[] moduleClasses = new String[classesListIValue.length];
    int i = 0;
    for (IValue iv : classesListIValue) {
      moduleClasses[i++] = iv.toStr();
    }

    输入文本使用 UTF-8 编码转换为 Java 字节数组。Tensor.fromBlobUnsigned 从该字节数组创建 dtype=uint8 的 tensor。

        byte[] bytes = text.getBytes(Charset.forName("UTF-8"));
    final long[] shape = new long[]{1, bytes.length};
    final Tensor inputTensor = Tensor.fromBlobUnsigned(bytes, shape);

    模型推理的运行与之前的示例类似：

    Tensor outputTensor = mModule.forward(IValue.from(inputTensor)).toTensor()

    之后，代码处理输出，找到得分最高的类别。

    构建 PyTorch Android 源代码。

    在某些情况下，您可能想使用本地构建的 PyTorch Android，例如，您可能需要使用另一组操作符构建自定义 LibTorch 二进制文件，或进行本地更改，或尝试最新的 PyTorch 代码。

    您可以使用 ./scripts/build_pytorch_android.sh 脚本完成此操作。

    git clone https://github.com/pytorch/pytorch.git
cd pytorch
sh ./scripts/build_pytorch_android.sh

    工作流程包含多个步骤：

    1. 为所有 4 个 Android ABI（armeabi-v7a、arm64-v8a、x86、x86_64）构建 libtorch for android


    2. 创建指向这些构建结果的符号链接： android/pytorch_android/src/main/jniLibs/${abi} 到输出库的目录 将头文件目录添加到路径中。这些目录用于构建 libpytorch_jni.so 库，作为 pytorch_android-release.aar 包的一部分，该包将在安卓设备上加载。

    最后，在 android/pytorch_android 目录下运行 gradle，执行 assembleRelease 任务。

    脚本要求安装 Android SDK、Android NDK、Java SDK 和 gradle。它们被指定为环境变量：

    ANDROID_HOME - Android SDK 的路径

    ANDROID_NDK - 路径到 Android NDK。建议使用 NDK 21.x。

    GRADLE_HOME - 路径到 gradle

    JAVA_HOME - 路径到 JAVA JDK

    构建成功后，你应该看到结果为 aar 文件：

    $ find android -type f -name *aar
android/pytorch_android/build/outputs/aar/pytorch_android-release.aar
android/pytorch_android_torchvision/build/outputs/aar/pytorch_android_torchvision-release.aar

    使用从源代码构建或夜间构建的 PyTorch Android 库

    首先将上面构建的两个 aar 文件或从夜间构建的 PyTorch Android 仓库中下载的 aar 文件添加到 Android 项目的 lib 文件夹中，然后在项目的 appbuild.gradle 文件中添加：

    allprojects {
    repositories {
        flatDir {
            dirs 'libs'
        }
    }
}

dependencies {

    // if using the libraries built from source
    implementation(name:'pytorch_android-release', ext:'aar')
    implementation(name:'pytorch_android_torchvision-release', ext:'aar')

    // if using the nightly built libraries downloaded above, for example the 1.8.0-snapshot on Jan. 21, 2021
    // implementation(name:'pytorch_android-1.8.0-20210121.092759-172', ext:'aar')
    // implementation(name:'pytorch_android_torchvision-1.8.0-20210121.092817-173', ext:'aar')

    ...
    implementation 'com.android.support:appcompat-v7:28.0.0'
    implementation 'com.facebook.fbjni:fbjni-java-only:0.0.3'
}

    此外，我们还需要添加我们 aar 的所有传递依赖项。由于 pytorch_android 依赖于 com.android.support:appcompat-v7:28.0.0 或 androidx.appcompat:appcompat:1.2.0 ，我们需要选择其中之一。（如果使用 maven 依赖项，它们会自动从 pom.xml 中添加）。

    使用夜间构建的 PyTorch Android 库

    除了使用从源代码构建或从上一节中的链接下载的 aar 文件外，您还可以通过在您的 app build.gradle 文件中添加 maven URL 和夜间构建库实现来使用夜间构建的 Android PyTorch 和 TorchVision 库：

    repositories {
    maven {
        url "https://oss.sonatype.org/content/repositories/snapshots"
    }
}

dependencies {
    ...
    implementation 'org.pytorch:pytorch_android:1.8.0-SNAPSHOT'
    implementation 'org.pytorch:pytorch_android_torchvision:1.8.0-SNAPSHOT'
}

    如果您不需要进行任何本地更改，这是尝试最新 PyTorch 代码和 Android 库的最简单方法。但请注意，您可能需要使用最新的 PyTorch 构建在移动设备上使用的模型 - 要么使用最新的 PyTorch 代码，要么使用如 pip install --pre torch torchvision -f https://download.pytorch.org/whl/nightly/cpu/torch_nightly.html 的命令进行快速夜间安装，以避免在移动设备上运行模型时可能出现的模型版本不匹配错误。

    自定义构建

    为了减小二进制文件的大小，您可以自定义构建 PyTorch Android，仅包含您模型所需的操作集。这包括两个步骤：从您的模型准备操作列表，使用指定的列表重新构建 PyTorch Android。

    1. 验证您的 PyTorch 版本为 1.4.0 或更高版本。您可以通过检查 torch.__version__ 的值来完成此操作。

    2. 准备操作符列表

    您可以使用 Python API 函数 torch.jit.export_opnames() 以 yaml 格式准备您的序列化 torchscript 模型的操作符列表。要导出模型 MobileNetV2 中的操作符，请运行以下 Python 代码行：

    # Dump list of operators used by MobileNetV2:
import torch, yaml
model = torch.jit.load('MobileNetV2.pt')
ops = torch.jit.export_opnames(model)
with open('MobileNetV2.yaml', 'w') as output:
    yaml.dump(ops, output)

    3. 使用准备好的操作符列表构建 PyTorch Android。

    要构建带有准备好的 yaml 列表的 PyTorch Android，请在环境变量中指定 SELECTED_OP_LIST。同样，在参数中指定应构建哪些 Android ABIs；默认情况下，它会构建所有 4 个 Android ABIs。

    # Build PyTorch Android library customized for MobileNetV2:
SELECTED_OP_LIST=MobileNetV2.yaml scripts/build_pytorch_android.sh arm64-v8a

    构建成功后，您可以按照本教程前一个部分（从源代码构建 PyTorch Android）中的步骤将结果 aar 文件集成到您的 Android gradle 项目中。

    使用 PyTorch JIT 解释器

    PyTorch JIT 解释器在 1.9 版本之前是默认解释器（我们 PyTorch 解释器中大小效率不是最高的一个版本）。它将在 1.9 版本中继续得到支持，并且可以通过 build.gradle 使用：

    repositories {
    jcenter()
}

dependencies {
    implementation 'org.pytorch:pytorch_android:1.9.0'
    implementation 'org.pytorch:pytorch_android_torchvision:1.9.0'
}

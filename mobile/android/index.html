    安卓

    使用 HelloWorld 示例快速入门

    HelloWorld 是一个简单的图像分类应用，演示了如何使用 PyTorch Android API。此应用在静态图像上运行 TorchScript 序列化的 TorchVision 预训练 resnet18 模型，该图像作为安卓资源打包在应用内部。

    1. 模型准备

    让我们从模型准备开始。如果你熟悉 PyTorch，你可能已经知道如何训练和保存你的模型。如果你不熟悉，我们将使用一个预训练的图像分类模型（MobileNetV2）。要安装它，请运行以下命令：

    pip install torchvision

    要序列化模型，你可以在 HelloWorld 应用的根目录中使用 python 脚本：

    import torch
import torchvision
from torch.utils.mobile_optimizer import optimize_for_mobile

model = torchvision.models.mobilenet_v2(pretrained=True)
model.eval()
example = torch.rand(1, 3, 224, 224)
traced_script_module = torch.jit.trace(model, example)
traced_script_module_optimized = optimize_for_mobile(traced_script_module)
traced_script_module_optimized._save_for_lite_interpreter("app/src/main/assets/model.ptl")

    如果一切顺利，我们应该在我们的模型 - model.ptl 中拥有它，它在安卓应用程序的 assets 文件夹中。它将被打包在安卓应用程序的 asset 中，可以在设备上使用。

    您可以在 pytorch.org 上的教程中找到更多关于 TorchScript 的详细信息

    2. 从 github 克隆

    git clone https://github.com/pytorch/android-demo-app.git
cd HelloWorldApp

    如果 Android SDK 和 Android NDK 已经安装，您可以使用以下命令将此应用程序安装到连接的 Android 设备或模拟器：

    ./gradlew installDebug

    我们建议您使用 Android Studio 3.5.1+打开此项目。目前 PyTorch Android 和演示应用程序使用 android gradle plugin 的版本 3.5.0，该版本仅由 Android Studio 版本 3.5.1 及以上支持。使用 Android Studio，您将能够通过 Android Studio UI 安装 Android NDK 和 Android SDK。

    3. Gradle 依赖项

    在 HelloWorld 中添加 Pytorch android 作为 gradle 依赖项到 build.gradle 文件中：

    repositories {
    jcenter()
}

dependencies {
    implementation 'org.pytorch:pytorch_android_lite:1.9.0'
    implementation 'org.pytorch:pytorch_android_torchvision:1.9.0'
}

    org.pytorch:pytorch_android 是主要依赖项，包含 PyTorch Android API，以及适用于所有 4 个 Android ABI（armeabi-v7a、arm64-v8a、x86、x86_64）的 libtorch 本地库。在此文档中，您可以找到如何仅针对特定列表的 Android ABI 重新构建它的方法。

    org.pytorch:pytorch_android_torchvision - 额外的库，包含将 android.media.Image 和 android.graphics.Bitmap 转换为张量的实用函数。

    4. 从 Android Asset 读取图像

    所有逻辑都在 org.pytorch.helloworld.MainActivity 中发生。作为第一步，我们使用标准的 Android API 读取 image.jpg 到 android.graphics.Bitmap 。

    Bitmap bitmap = BitmapFactory.decodeStream(getAssets().open("image.jpg"));

    5. 加载移动模块

    Module module = Module.load(assetFilePath(this, "model.ptl"));

    org.pytorch.Module 代表可以通过 load 方法加载的 torch::jit::mobile::Module ，该方法指定了保存到文件的模型文件路径。

    6. 准备输入

    Tensor inputTensor = TensorImageUtils.bitmapToFloat32Tensor(bitmap,
    TensorImageUtils.TORCHVISION_NORM_MEAN_RGB, TensorImageUtils.TORCHVISION_NORM_STD_RGB);

    org.pytorch.torchvision.TensorImageUtils 是 org.pytorch:pytorch_android_torchvision 库的一部分。 TensorImageUtils#bitmapToFloat32Tensor 方法使用 android.graphics.Bitmap 作为源创建 torchvision 格式的张量。

    所有预训练模型都期望输入图像以相同的方式进行归一化，即形状为 (3 x H x W) 的 3 通道 RGB 图像的 mini-batches，其中 H 和 W 至少为 224。图像必须加载到 [0, 1] 范围内，然后使用 mean = [0.485, 0.456, 0.406] 和 std = [0.229, 0.224, 0.225] 进行归一化。

    inputTensor 的形状是 1x3xHxW ，其中 H 和 W 是适当的位图高度和宽度。

    7. 运行推理

    Tensor outputTensor = module.forward(IValue.from(inputTensor)).toTensor();
float[] scores = outputTensor.getDataAsFloatArray();

    org.pytorch.Module.forward 方法运行加载的模块的 forward 方法，并将结果作为 org.pytorch.Tensor 输出张量 1x1000 的形状返回。

    8. 处理结果

    其内容通过 org.pytorch.Tensor.getDataAsFloatArray() 方法检索，该方法返回每个图像网络类得分的浮点数数组。

    之后我们只需找到具有最高分数的索引，并从包含所有 ImageNet 类名的 ImageNetClasses.IMAGENET_CLASSES 数组中检索预测的类名。

    float maxScore = -Float.MAX_VALUE;
int maxScoreIdx = -1;
for (int i = 0; i < scores.length; i++) {
  if (scores[i] > maxScore) {
    maxScore = scores[i];
    maxScoreIdx = i;
  }
}
String className = ImageNetClasses.IMAGENET_CLASSES[maxScoreIdx];

    在以下章节中，您可以找到 PyTorch Android API 的详细说明、更大演示应用程序的代码演示、API 的实现细节以及如何自定义和从源代码构建它。

    PyTorch 演示应用程序

    我们还在同一 GitHub 仓库中创建了一个更复杂的 PyTorch Android 演示应用程序，该应用程序可以从相机输出中进行图像分类，并在同一仓库中进行文本分类。

    获取设备相机输出时使用 Android CameraX API。与 CameraX 相关的所有逻辑都分离到 org.pytorch.demo.vision.AbstractCameraXActivity 类中。

    void setupCameraX() {
    final PreviewConfig previewConfig = new PreviewConfig.Builder().build();
    final Preview preview = new Preview(previewConfig);
    preview.setOnPreviewOutputUpdateListener(output -> mTextureView.setSurfaceTexture(output.getSurfaceTexture()));

    final ImageAnalysisConfig imageAnalysisConfig =
        new ImageAnalysisConfig.Builder()
            .setTargetResolution(new Size(224, 224))
            .setCallbackHandler(mBackgroundHandler)
            .setImageReaderMode(ImageAnalysis.ImageReaderMode.ACQUIRE_LATEST_IMAGE)
            .build();
    final ImageAnalysis imageAnalysis = new ImageAnalysis(imageAnalysisConfig);
    imageAnalysis.setAnalyzer(
        (image, rotationDegrees) -> {
          analyzeImage(image, rotationDegrees);
        });

    CameraX.bindToLifecycle(this, preview, imageAnalysis);
  }

  void analyzeImage(android.media.Image, int rotationDegrees)

    analyzeImage 方法处理相机输出， android.media.Image 。

    使用上述 TensorImageUtils.imageYUV420CenterCropToFloat32Tensor 方法将 android.media.Image 转换为 YUV420 格式的输入张量。

    从模型获取预测分数后，找到分数最高的前 K 个类别并在 UI 上显示。

    语言处理示例

    另一个例子是基于 LSTM 模型的自然语言处理，该模型在 Reddit 评论数据集上训练。逻辑发生在 TextClassificattionActivity 。

    结果类名打包在 TorchScript 模型中，并在初始化模块后立即初始化。该模块有一个 get_classes 方法，该方法返回 List[str] ，可以使用方法 Module.runMethod(methodName) 调用：

        mModule = Module.load(moduleFileAbsoluteFilePath);
    IValue getClassesOutput = mModule.runMethod("get_classes");

    返回的 IValue 可以使用 IValue.toList() 转换为 IValue 的 Java 数组，然后使用 IValue.toStr() 处理成字符串数组：

        IValue[] classesListIValue = getClassesOutput.toList();
    String[] moduleClasses = new String[classesListIValue.length];
    int i = 0;
    for (IValue iv : classesListIValue) {
      moduleClasses[i++] = iv.toStr();
    }

    输入文本被转换为使用 UTF-8 编码的字节 Java 数组。 Tensor.fromBlobUnsigned 从该字节数组创建 dtype=uint8 的张量。

        byte[] bytes = text.getBytes(Charset.forName("UTF-8"));
    final long[] shape = new long[]{1, bytes.length};
    final Tensor inputTensor = Tensor.fromBlobUnsigned(bytes, shape);

    运行模型的推理与之前的示例类似：

    Tensor outputTensor = mModule.forward(IValue.from(inputTensor)).toTensor()

    之后，代码处理输出，找到得分最高的类别。

    从源代码构建 PyTorch Android

    在某些情况下，您可能想使用本地构建的 PyTorch Android，例如，您可能想使用另一组操作符构建自定义 LibTorch 二进制文件，或进行本地更改，或尝试最新的 PyTorch 代码。

    您可以使用 ./scripts/build_pytorch_android.sh 脚本来完成此操作。

    git clone https://github.com/pytorch/pytorch.git
cd pytorch
sh ./scripts/build_pytorch_android.sh

    工作流程包含多个步骤：

    1. 为所有 4 个 Android ABIs（armeabi-v7a、arm64-v8a、x86、x86_64）构建 libtorch for android

    2. 创建构建结果的符号链接： android/pytorch_android/src/main/jniLibs/${abi} 指向输出库目录， android/pytorch_android/src/main/cpp/libtorch_include/${abi} 指向头文件目录。这些目录用于构建 libpytorch_jni.so 库，作为 pytorch_android-release.aar 包的一部分，该包将在 Android 设备上加载。

    3. 最后，在 android/pytorch_android 目录下运行 gradle 任务

    4. 脚本要求安装 Android SDK、Android NDK、Java SDK 和 gradle。它们作为环境变量指定：

    ANDROID_HOME - Android SDK 路径

    ANDROID_NDK - Android NDK 路径。建议使用 NDK 21.x 版本。

    GRADLE_HOME - gradle 路径

    JAVA_HOME - JAVA JDK 路径

    构建成功后，你应该看到结果为 aar 文件：

    $ find android -type f -name *aar
android/pytorch_android/build/outputs/aar/pytorch_android-release.aar
android/pytorch_android_torchvision/build/outputs/aar/pytorch_android_torchvision-release.aar

    使用从源代码或夜间构建的 PyTorch Android 库

    首先将上面构建的两个 aar 文件或从夜间构建的 PyTorch Android 仓库中下载的 aar 文件添加到 Android 项目的 lib 文件夹中，然后添加到项目的 app build.gradle 文件中：

    allprojects {
    repositories {
        flatDir {
            dirs 'libs'
        }
    }
}

dependencies {

    // if using the libraries built from source
    implementation(name:'pytorch_android-release', ext:'aar')
    implementation(name:'pytorch_android_torchvision-release', ext:'aar')

    // if using the nightly built libraries downloaded above, for example the 1.8.0-snapshot on Jan. 21, 2021
    // implementation(name:'pytorch_android-1.8.0-20210121.092759-172', ext:'aar')
    // implementation(name:'pytorch_android_torchvision-1.8.0-20210121.092817-173', ext:'aar')

    ...
    implementation 'com.android.support:appcompat-v7:28.0.0'
    implementation 'com.facebook.fbjni:fbjni-java-only:0.0.3'
}

    此外，我们还需要添加我们 aar 的所有传递依赖。由于 pytorch_android 依赖于 com.android.support:appcompat-v7:28.0.0 或 androidx.appcompat:appcompat:1.2.0 ，我们需要其中一个。（如果使用 maven 依赖，它们会自动从 pom.xml 添加）。

    使用 PyTorch Android 夜间库

    除了使用上一节中从源代码构建或下载的 aar 文件外，您还可以通过在您的 app build.gradle 文件中添加 maven URL 和夜间构建的 Android PyTorch 和 TorchVision 库的实现来使用夜间构建的 Android PyTorch 和 TorchVision 库：

    repositories {
    maven {
        url "https://oss.sonatype.org/content/repositories/snapshots"
    }
}

dependencies {
    ...
    implementation 'org.pytorch:pytorch_android:1.8.0-SNAPSHOT'
    implementation 'org.pytorch:pytorch_android_torchvision:1.8.0-SNAPSHOT'
}

    这是最简单的方法来尝试最新的 PyTorch 代码和 Android 库，如果您不需要进行任何本地更改。但请注意，您可能需要使用最新的 PyTorch 构建在移动设备上使用的模型 - 使用最新的 PyTorch 代码或使用类似 pip install --pre torch torchvision -f https://download.pytorch.org/whl/nightly/cpu/torch_nightly.html 的快速夜间安装命令 - 以避免在移动设备上运行模型时可能出现的模型版本不匹配错误。

    自定义构建

    为了减小二进制文件的大小，您可以仅使用模型所需的操作符自定义构建 PyTorch Android。这包括两个步骤：从您的模型中准备操作符列表，使用指定的列表重新构建 PyTorch Android。

    1. 验证您的 PyTorch 版本为 1.4.0 或更高版本。您可以通过检查 torch.__version__ 的值来完成此操作。

    2. 准备操作符列表

    您可以使用 Python API 函数 torch.jit.export_opnames() 以 yaml 格式准备您的序列化 torchscript 模型的操作符列表。要导出模型中的操作符，例如 MobileNetV2 ，请运行以下 Python 代码行：

    # Dump list of operators used by MobileNetV2:
import torch, yaml
model = torch.jit.load('MobileNetV2.pt')
ops = torch.jit.export_opnames(model)
with open('MobileNetV2.yaml', 'w') as output:
    yaml.dump(ops, output)

    3. 使用准备好的算子列表构建 PyTorch Android。

    要使用准备好的算子 yaml 列表构建 PyTorch Android，请在环境变量中指定它 SELECTED_OP_LIST 。同时，在参数中指定应构建哪些 Android ABIs；默认情况下，它构建所有 4 个 Android ABIs。

    # Build PyTorch Android library customized for MobileNetV2:
SELECTED_OP_LIST=MobileNetV2.yaml scripts/build_pytorch_android.sh arm64-v8a

    构建成功后，您可以按照本教程前一个部分（从源代码构建 PyTorch Android）中的步骤将结果 aar 文件集成到您的 Android gradle 项目中。

    使用 PyTorch JIT 解释器

    PyTorch JIT 解释器在 1.9 版本之前是默认解释器（我们 PyTorch 解释器的一种，但大小效率不高）。它将在 1.9 版本中仍然得到支持，可以通过 build.gradle :来使用。

    repositories {
    jcenter()
}

dependencies {
    implementation 'org.pytorch:pytorch_android:1.9.0'
    implementation 'org.pytorch:pytorch_android_torchvision:1.9.0'
}

PyTorch 基金会行为准则

我们的承诺

PyTorch 基金会致力于为所有参与 PyTorch 基金会社区的人营造一个包容、欢迎和安全的环境。这一承诺适用于基金会所有活动，包括但不限于我们的技术项目、活动、沟通渠道和社交媒体存在。我们承诺为所有人提供一个无骚扰的社区参与体验，无论年龄、体型、残疾、种族、性别特征、性别认同和表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、宗教或性取向和性身份。

范围

本行为准则适用于 PyTorch 基金会董事会会议、技术顾问委员会会议和 Outreach 项目（如大使计划）以及 PyTorch 基金会任何其他未由 Linux 基金会或适用技术项目的行为准则所涵盖的活动。

PyTorch 基金会活动

由 Linux 基金会组织并由专业活动人员负责的 PyTorch 基金会活动，受 Linux 基金会活动行为准则的约束，该准则可在活动页面上找到，并旨在与 PyTorch 基金会行为准则一同使用。

PyTorch 基金会伞下的技术项目

由 PyTorch 基金会支持的技术项目被组织为独立的项目，每个项目都有一套适用于参与者的行为准则。

预期行为

社区成员应：

  • 使用欢迎和包容的语言
  • 尊重不同的观点和经验
  • 欣然接受建设性的批评
  • 优先考虑对整个社区有益的事情
  • 对他人表现出同情和善意
  • 在所有互动中保持专业和负责任
  • 在现场活动中遵守健康和安全要求
  • 在言语和行为中表现出考虑和尊重
  • 以建设性的方式与其他社区成员合作

不可接受的行为

以下行为在我们的社区中被视为不可接受：

骚扰和歧视

  • 任何形式的骚扰，无论是言语、身体还是视觉的
  • 基于受保护特征的歧视
  • 性骚扰或不受欢迎的性关注
  • 故意恐吓、跟踪或跟随
  • 持续干扰会谈、活动或在线讨论
  • 不适当的身体接触

沟通和内容

  • 使用性化语言或图像
  • 使用暴力或威胁性语言或图像
  • 恶搞、侮辱性/贬低性评论或人身攻击
  • 公共或私人骚扰
  • 未获许可发布他人私人信息
  • 使用基金会平台进行与科技无关的政治竞选或推广政治运动
  • 在专业环境中可能被认为不适当的其他行为

网络和社交媒体行为

  • 通过社交媒体平台进行的骚扰或欺凌
  • 散布关于基金会或其成员的虚假信息
  • 未获许可使用基金会频道进行商业推广
  • 创建多个账户以规避监管
  • 伪装基金会成员或官员

调查期间的行为

  • 在与行为准则调查相关的情况下故意提供虚假或误导性信息，或者故意篡改调查。
  • 因为某个人报告了事件或作为目击者提供了关于事件的信息而对其进行报复。

执法

报告违规行为

违规行为可发送至 conduct@pytorch.org 报告。所有报告都将：

  • 及时彻底审查
  • 严格保密处理
  • 适当调查并妥善解决
  • 为将来参考而记录

后果

违规可能导致：

  • 对违规者的警告
  • 基金会空间的临时或永久封禁
  • 被移除领导或贡献性角色
  • 无退款的情况下被驱逐出活动
  • 如有必要，向适当当局报告
  • 其他后果

上诉流程

  • 个人可以就执法决定提出上诉
  • 上诉必须在 30 天内以书面形式提交给 PyTorch 基金会，通过 conduct@pytorch.org 邮箱
  • 申诉决定为最终决定

活动前的担忧

如果您对参加即将举行的活动（可能存在特定人员）有担忧：

  • 请提前联系 conduct@pytorch.org
  • 可为您安排安全舒适的安排
  • 预防措施可能包括提供安保人员和通知工作人员

修订

本行为准则可根据需要由 PyTorch 基金会进行修订。变更将通知社区，并继续参与社区表示同意当前版本。

问题与报告 - 联系

如有疑问、担忧或报告：

邮箱：conduct@pytorch.org

致谢

本行为准则改编自可在以下链接找到的《贡献者公约》第 2.0 版。

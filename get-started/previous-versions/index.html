Conda

OSX

Linux 和 Windows
# CUDA 11.8
conda install pytorch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1  pytorch-cuda=11.8 -c pytorch -c nvidia

conda install pytorch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 pytorch-cuda=12.1 -c pytorch -c nvidia

低于1.0.0版本的命令

通过 conda

应用于大多数之前的 macOS 版本安装。

要通过 Anaconda 或 Miniconda 安装 PyTorch 的早期版本，请将以下命令中的“0.4.1”替换为所需的版本（例如，“0.2.0”）。

使用 CUDA 9 进行安装

conda install pytorch=0.4.1 cuda90 -c pytorch

或者

conda install pytorch=0.4.1 cuda92 -c pytorch

使用 CUDA 8 安装

conda install pytorch=0.4.1 cuda80 -c pytorch

使用 CUDA 7.5 安装

conda install pytorch=0.4.1 cuda75 -c pytorch

不使用 CUDA 安装

conda install pytorch=0.4.1 -c pytorch

从源


可以检出 PyTorch 的旧版本 并构建它。 您可以使用 git tag 列出 PyTorch 的 git 仓库中的标签，并检出特定的一个（将‘0.1.9’替换为所需的版本）

git checkout v0.1.9

请按照 PyTorch checkout 的 README.md 中的源安装说明进行操作。

通过 pip

从以下 html 页面下载所需版本的 whl 文件：

  • https://download.pytorch.org/whl/cpu/torch_stable.html # 仅 CPU 版本构建
  • https://download.pytorch.org/whl/cu80/torch_stable.html # CUDA 8.0 版本构建
  • https://download.pytorch.org/whl/cu90/torch_stable.html # CUDA 9.0 版本构建
  • https://download.pytorch.org/whl/cu92/torch_stable.html # CUDA 9.2 版本构建
  • https://download.pytorch.org/whl/cu100/torch_stable.html # CUDA 10.0 版本构建

然后，使用 pip install [下载的文件] 安装文件

注意：大多数 PyTorch 版本仅适用于特定的 CUDA 版本。例如，pytorch=1.0.1 不适用于 CUDA 9.2
